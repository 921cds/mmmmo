# Brand Mockup Board

브랜드 로고와 컬러·폰트를 넣으면 명함, 포스터, 앱 아이콘, 웹사이트, 티셔츠, 매장 사인 등 12종 목업을 무한 캔버스 위에 바로 만들어 주는 팀용 보드입니다.

## 실행

빌드 과정 없이 정적 파일만으로 동작합니다.

- 가장 간단한 방법: `index.html`을 Chrome에서 열기
- 팀 공유용: 이 폴더를 아무 정적 호스팅(사내 서버, GitHub Pages, Netlify 등)에 올리기

## 주요 기능

- **브랜드 키트**: 왼쪽 패널에 로고(SVG/PNG/JPG)를 끌어다 놓고 이름, 슬로건, Primary/Secondary 컬러, 서체를 정하면 모든 목업에 실시간 반영
- **무한 캔버스**: 스크롤로 이동, ⌘/Ctrl + 스크롤 또는 트랙패드 핀치로 확대·축소, Space 누른 채 드래그로 이동
- **자유 노트**: 빈 곳 더블클릭 또는 N 도구. 채우기·텍스트 색, 정렬, 굵기, 글자 크기(입력·슬라이더·⌘⇧< >) 조절
- **이미지 드래그 앤 드롭**: 파일을 캔버스에 드롭하거나 붙여넣기. 이미지를 선택해 "브랜드 로고로 사용" 가능
- **목업 설정**: 목업별 바탕 색, 로고 색(자동/원본/흰색/검정), 로고 크기, 템플릿 교체, PNG(3x) 내보내기
- **목업 디자인 편집**: 목업을 더블클릭(또는 "디자인 편집")하면 안의 로고·글자·도형을 하나씩 선택해 옮기기, 크기 조절, 문구·글자 크기·굵기·정렬, 색, 투명도를 바꿀 수 있어요. 텍스트·사각형·원·이미지를 새로 넣거나 요소를 숨길 수 있고, 이미지 파일을 목업 위에 드롭해도 들어가요. Esc 또는 "완료"로 나오고, "원래대로"로 언제든 되돌릴 수 있어요. 색을 Primary/Secondary로 지정한 요소는 브랜드 컬러를 바꾸면 함께 바뀌어요.
- **사진 클리핑 마스크**: 목업에 넣은 사진은 사각형·둥근 모서리·원 모양으로 잘라내거나, 목업 안의 다른 요소(원, 도형, 글자 등) 모양을 마스크로 쓸 수 있어요. 사진을 더블클릭하면 크롭 모드가 되어 드래그로 보이는 부분을 옮기고, "확대" 슬라이더로 키울 수 있어요.
- **요소 순서**: 편집 중 요소를 맨 앞/앞으로/뒤로/맨 뒤로 보낼 수 있어요(] / [ 키). 사진을 배경처럼 글자 뒤에 깔 수 있어요.
- 선택·다중 선택(드래그 영역, Shift), 리사이즈, 정렬, 복제, 레이어 순서, 실행 취소/다시 실행

## 저장과 공유

- 작업 내용은 브라우저(localStorage)에 자동 저장됩니다. 브라우저·기기마다 따로 저장돼요.
- 팀원과 공유하려면 메뉴(⋯) → **보드 파일로 저장(.json)** 후 전달하고, 받은 사람은 **보드 파일 열기**로 불러오면 됩니다.
- 큰 이미지를 많이 넣으면 브라우저 저장 공간이 부족할 수 있어요. 그때는 보드 파일로 저장하세요.

## 파일 구성

- `index.html` — 화면 구조
- `styles.css` — Figma UI3 스타일의 미니멀 UI
- `mockups.js` — 목업 템플릿(SVG). 새 목업은 `templates`에 항목을 추가하면 메뉴와 "목업 전체 생성"에 자동으로 들어갑니다.
- `app.js` — 캔버스, 선택·편집, 저장 로직
